# 页面操作

页面（Page）是 Notion 的基本单位。一切内容——笔记、文档、项目计划、会议记录——最终都存放在页面里。上一章你已经让 Agent 创建了第一个页面，本章将系统地介绍页面的全部操作：创建、编辑、移动、删除，以及一些进阶用法。

## 创建页面

### 最简单的方式

> 💬 **你：**
> "帮我创建一个页面，标题叫'项目备忘录'"

Agent 会在你的个人空间（顶层私人页面）创建一个新页面。这是最简单的情况——你不指定位置，Agent 就默认放在你的个人空间。

### 指定页面位置

页面不是漂浮在空中的，它必须有一个"家"——也就是**父级**（Parent）。Notion 中有四种你可以使用的父级类型：

| 父级类型 | 说明 | 示例指令 |
|---------|------|----------|
| 个人空间 | 你的私人顶层区域 | "创建一个页面"（默认） |
| 页面 | 放在另一个页面下面，成为子页面 | "在 @周报 下面创建一个子页面" |
| 数据库 | 作为数据库的一条记录 | "在任务数据库里新建一条任务" |
| 团队空间 | 放在某个 Teamspace 的顶层 | "在产品团队空间里创建一个页面" |

> 💡 **提示**：用 @ 提及来告诉 Agent 你想把页面放在哪里。比如 "在 @项目文档 下面创建一个子页面"。

### 带内容地创建

你不必先创建空页面再填内容——可以一步到位：

> 💬 **你：**
> "帮我创建一个读书笔记页面，标题'原子习惯'，内容包括：一个二级标题'核心观点'，下面列三个要点：习惯的复利效应、系统比目标重要、身份认同驱动行为"

Agent 会创建页面并填好内容，省去你来回跑的功夫。

### 图标

Agent 创建页面时通常会自动加一个图标（emoji）。你也可以指定：

> 💬 **你：**
> "创建一个页面叫'紧急事项'，图标用 🔥"

如果你不想要图标，可以说"不加图标"。

## 编辑页面

编辑页面是你最常用的操作之一。Agent 支持两种编辑维度：**编辑内容**和**编辑属性**。

### 编辑内容

内容就是页面的正文——标题、段落、列表、表格等等。

**追加内容**：

> 💬 **你：**
> "在 @会议纪要 页面的末尾加上一段：下次会议时间为周五下午3点"

**修改现有内容**：

> 💬 **你：**
> "把 @项目计划 里的'第一阶段截止日期：3月15日'改成'第一阶段截止日期：3月30日'"

Agent 编辑内容的原理是**查找替换**——它找到页面中的一段文字（oldStr），用新文字（newStr）替换掉。所以：

- 你描述得越准确，Agent 找到目标的概率越高
- 如果页面里有多处相同的文字，Agent 需要更多上下文来区分

**全量替换**（用于重写整个页面）：

> 💬 **你：**
> "把 @草稿 页面的内容全部替换为以下内容：……"

Agent 会用你给的新内容替换掉整个页面。这是"最后手段"——通常局部编辑更安全。

> ⚠️ **确定性陷阱 #3：对 locked 或 deleted 页面编辑会失败。** 如果你的页面被锁定或已删除，Agent 无法编辑。需要先在 Notion UI 里解锁页面，或者恢复已删除的页面。

### 编辑属性

如果页面在数据库中，它除了内容还有**属性**（Properties）——比如状态、标签、负责人、截止日期等。

> 💬 **你：**
> "把 @需求评审 的状态改为'进行中'，负责人设为我"

Agent 会更新这个数据库页面的 Status 和 Person 属性。

关于属性的更多细节（属性类型、日期格式、关联等），我们会在第四章"数据库操作"中详细介绍。这里只需要知道：Agent 可以帮你改属性，但你需要用数据库里已有的属性名和选项名。

> ⚠️ **确定性陷阱 #4：属性名区分大小写。** 数据库中的属性叫 "Status"，你让 Agent 改 "status"（小写 s），可能不会生效。尽量用准确的属性名，或者用 @ 提及让 Agent 自己去查。

## 移动页面

页面放错了地方？让 Agent 搬：

> 💬 **你：**
> "把 @旧笔记 移到 @归档文件夹 下面"

Agent 会修改页面的父级，把它从原来的位置移到你指定的新位置。

注意几点：
- 移动是**真正的移动**，不是创建快捷方式或副本
- 你可以在页面、数据库、团队空间之间自由移动
- 移动到数据库时，页面会获得该数据库的属性结构

## 删除与归档

Notion 提供两种"移除"页面的方式：

### 删除

> 💬 **你：**
> "删除 @测试页面"

删除会将页面移到回收站。在 Notion 中，回收站里的页面可以在一定时间内恢复。但 Agent 只能删除，不能从回收站恢复——恢复需要你在 Notion UI 里手动操作。

### 归档

> 💬 **你：**
> "归档 @Q2项目计划"

归档不同于删除——页面还在工作区中，只是被隐藏了。你可以随时让 Agent 取消归档：

> 💬 **你：**
> "取消归档 @Q2项目计划"

**什么时候用删除，什么时候用归档？**

- **删除**：你确定不再需要这个页面
- **归档**：暂时不用，但以后可能还会看

## 页面内容格式

Agent 能写出什么样的页面内容？答案是：几乎所有 Notion 支持的格式。

### 基础格式

这些是最常用的，你直接用自然语言描述就行：

- **标题**（H1/H2/H3）："加一个二级标题'项目目标'"
- **列表**（有序/无序/待办）："列一个待办清单"
- **表格**："插入一个三列表格"
- **代码块**："加一段 Python 代码"
- **引用**："引用这段话"
- **分割线**："加一条分割线"
- **数学公式**："插入一个行内公式"

### Notion 特色格式

Notion 有一些独特的内容块，Agent 也能创建：

- **Callout（提示框）**：带图标的高亮文本块，适合强调重要信息
  > 💬 "加一个黄色的提示框，图标用 ⚡，内容是'注意截止日期'"

- **Toggle（折叠块）**：点击展开/收起的内容
  > 💬 "创建一个折叠块，标题是'详细说明'，里面写上实施步骤"

- **Columns（分栏）**：将内容分成多列
  > 💬 "把优点和缺点分成两栏展示"

- **Synced Block（同步块）**：在多个页面间同步的内容
  > 💬 "创建一个同步块，内容是团队联系方式"

- **Mention（提及）**：行内引用一个页面、用户或日期
  > 💬 "在这里提及 @张三 和 @项目规划 页面"

### 颜色

Notion 支持为文本和块添加颜色：

- **文本颜色**：gray, brown, orange, yellow, green, blue, purple, pink, red
- **背景颜色**：在颜色名后加 `_bg`，如 `red_bg`, `blue_bg`

> 💬 "把'重要提醒'这几个字标成红色" 或 "给这段话加蓝色背景"

### 媒体内容

Agent 可以在页面中嵌入图片、视频、音频、PDF 和文件。不过，Agent 不能"上传"文件——它只能引用已经在 Notion 中的文件或网络上的 URL。

## 分享与权限

Agent 可以帮你管理页面的分享设置：

> 💬 **你：**
> "把 @产品路线图 分享给整个工作区，权限设为只读"

或者：

> 💬 **你：**
> "把 @产品路线图 发布到网上"

权限从高到低有六个级别：

| 权限级别 | 说明 |
|---------|------|
| 完全访问 | 可编辑内容、结构和分享设置 |
| 可编辑 | 可编辑内容，不能改分享设置 |
| 可编辑内容 | 可编辑数据库内容，不能改结构 |
| 可评论 | 只能评论 |
| 可查看 | 只读 |
| 无权限 | 移除访问 |

分享对象有三种：
- **特定用户**：分享给某个人
- **工作区**：分享给工作区所有成员
- **公开（Share to Web）**：发布到互联网

## 页面验证（Verification）

如果你的团队有文档质量管理的需求，可以用验证功能：

> 💬 **你：**
> "把 @API文档 标记为已验证"

验证是 Notion 内置的页面级属性，适合标记文档的审核状态。你也可以设置过期天数——比如验证后 90 天自动过期，提醒团队重新审核。

## Presentation Mode（演示模式）

Notion 页面可以直接作为幻灯片演示（需要 Plus 计划及以上）：

> 💬 **你：**
> "帮我创建一个产品发布的演示文稿，包含以下幻灯片：封面、产品亮点、技术架构、上市计划、Q&A"

Agent 会创建一个页面，用分割线（`---`）分隔每张幻灯片。你可以在 Notion 中用 Cmd+Option+P（Mac）或 Ctrl+Alt+P（Windows）开始演示。

## 模板

如果某个数据库里的页面经常需要同样的结构，可以让 Agent 创建模板：

> 💬 **你：**
> "在任务数据库里创建一个模板，标题叫'Bug 报告模板'，内容包括：问题描述、复现步骤、预期行为、实际行为"

Agent 会在该数据库的数据源中创建一个模板页。之后每次在数据库中新建页面时，都可以选择这个模板。

## 实用技巧

### 一次说清楚，减少来回

Agent 每次操作都消耗对话上下文。与其分五步创建一个复杂页面，不如一次描述清楚：

> ❌ 不推荐（五轮对话）：
> 1. "创建一个页面叫项目计划"
> 2. "加个图标"
> 3. "加一个二级标题'目标'"
> 4. "加一个表格"
> 5. "把页面移到团队空间"

> ✅ 推荐（一轮对话）：
> "在产品团队空间创建一个页面叫'项目计划'，图标用 🎯，内容包括：一个二级标题'目标'，下面写一段简要说明，再加一个三列表格（里程碑、负责人、截止日期），里面预填三行示例数据"

### 用 @ 提及来精确定位

当你要操作已有页面时，@ 提及是最可靠的方式。它直接给 Agent 一个精确的页面地址，省去搜索的步骤。

### 检查 Agent 的编辑结果

Agent 编辑页面后，点击回复中的链接去看看实际效果。特别是：
- 表格的格式是否正确
- 内容是否被放在了正确的位置
- 属性值是否生效

## 本章小结

- **创建页面**：指定父级（个人空间/页面/数据库/团队空间），可一步到位带内容和图标
- **编辑页面**：内容编辑基于查找替换，属性编辑需要准确的属性名
- **移动页面**：改变父级即可，是真正的移动而非复制
- **删除 vs 归档**：删除进回收站，归档只是隐藏
- **内容格式**：几乎支持所有 Notion 块类型——标题、列表、表格、callout、toggle、columns 等
- **分享**：可设置用户/工作区/公开三种维度的权限
- **模板**：在数据库中创建可复用的页面结构
- **演示模式**：用分割线分隔，页面变幻灯片

下一章，我们进入数据库的世界——Notion 最强大的结构化数据工具。
