# 搜索与信息获取

到目前为止，你已经学会了让 Agent 创建和编辑页面、操作数据库。但日常工作中，你更常见的需求可能是：**找东西**。

"上次的会议记录在哪？"
"WiFi 密码是什么？"
"Q3 路线图有更新吗？"

这一章，我们来系统了解 Agent 的搜索能力。

## Agent 能搜什么

Agent 的搜索范围远超你的想象。它不只是搜你的 Notion 工作区——它可以同时搜索：

- **Notion 工作区**：所有你有权限访问的页面、数据库、评论
- **连接的外部工具**：Slack 消息、Google Drive 文件、GitHub 代码、Jira 工单、Gmail 邮件、日历事件等
- **互联网**：公开的网页、新闻、文档

这意味着你可以用一句话，让 Agent 跨越多个信息源去寻找答案。

## 基本搜索

### 搜工作区内容

> 💬 **你：**
> "帮我找一下关于年度预算的页面"

Agent 会在你的 Notion 工作区中搜索，返回最相关的结果。

> 💬 **你：**
> "WiFi 密码是什么"

Agent 会搜索工作区中可能包含 WiFi 密码的页面。这是语义搜索——即使页面标题叫"办公室信息"而不是"WiFi 密码"，Agent 也可能找到它。

### 搜外部工具

如果你的工作区连接了 Slack、Google Drive 等外部工具，Agent 也能搜到那里的内容：

> 💬 **你：**
> "上周 Slack 里有没有人提到过部署延期"

Agent 会搜索 Slack 消息，找到相关的讨论。

> 💬 **你：**
> "找一下 Google Drive 里的产品需求文档"

### 搜互联网

> 💬 **你：**
> "查一下 React 19 有哪些新特性"

Agent 会搜索互联网并返回最新的信息。

> ⚠️ **注意**：Agent 的搜索**默认包含互联网结果**。如果你只想搜工作区和连接的工具，可以明确说"只在我的工作区里搜索"。

## 搜索技巧

### 用自然语言描述需求

Agent 支持语义搜索——你不需要猜测精确的关键词，用自然语言描述你要找的东西就行：

> ✅ "找一下上次产品评审会的笔记" （自然语言，效果好）
>
> ❌ "产品 评审 笔记 2024" （堆砌关键词，不一定更好）

### 指定时间范围

如果你知道大概的时间范围，告诉 Agent 可以显著提高搜索精度：

> 💬 "找一下上个月修改过的 API 文档"
>
> 💬 "搜索最近一周内关于发布计划的讨论"

### 排除不需要的来源

> 💬 "只在 Notion 里搜索报销政策"（排除互联网）
>
> 💬 "搜一下 Slack 里关于服务器迁移的消息"（指定来源）

### 多个问题一起问

如果你有多个不同的搜索需求，可以一次性提出——Agent 会并行搜索：

> 💬 "帮我查一下：1）下次团建的时间和地点 2）报销标准是多少"

Agent 会分别搜索这两个问题，然后一起回复你。

## 搜索结果的使用

Agent 不只是甩给你一堆链接——它会：

1. **理解并总结结果**：用自然语言告诉你找到了什么
2. **引用来源**：每条信息都标注出处，你可以点击跳转到原始页面
3. **跨源综合**：如果多个来源提到了同一件事，Agent 会综合信息

比如你问"下个季度的目标是什么"，Agent 可能会综合 Notion 里的 OKR 页面和 Slack 里老板发的消息，给你一个完整的答案。

## 网页浏览

除了搜索，Agent 还能帮你阅读网页：

> 💬 **你：**
> "帮我看看这个链接说了什么：https://example.com/article"

Agent 会抓取网页内容并总结给你。这在以下场景很有用：

- 同事分享了一个链接，你想快速了解内容
- 需要从某个网页提取特定信息
- 想让 Agent 基于网页内容做进一步操作（比如总结后写到 Notion 页面里）

> 💡 **提示**：如果网页内容很长，Agent 会自动截取最相关的部分。如果你需要完整内容，可以让 Agent 继续读取剩余部分。

## 搜索的局限性

了解搜索的限制很重要：

### 权限限制

Agent 只能搜到你有权限访问的内容。如果某个页面只有特定人可以查看，Agent 也看不到。

### 连接限制

外部工具（Slack、Google Drive 等）需要先在 Notion 设置中连接。如果没有连接，Agent 就搜不到那些来源的内容。

> 💡 **设置方法**：在 Notion 的"设置与成员" → "连接"中添加外部服务。具体步骤可以问 Agent："怎么连接 Slack 到 Notion？"

### 结果数量限制

搜索结果有数量上限。如果你需要的信息在很多相似页面中，Agent 返回的可能不是最完美的那个。你可以通过更具体的描述来缩小范围。

### 时效性

- Notion 内容的搜索几乎是实时的
- 连接源的搜索可能有轻微延迟（取决于同步频率）
- 互联网搜索反映的是搜索引擎的最新索引

## Notion 帮助文档

如果你遇到 Notion 产品使用上的问题，Agent 也能帮忙：

> 💬 "怎么在 Notion 里设置页面锁定？"
>
> 💬 "Notion 的免费版和付费版有什么区别？"

Agent 会搜索 Notion 官方帮助文档，给你准确的产品使用指南。

## 实用场景

### 找文档

> 💬 "公司的休假政策在哪？"

### 找信息

> 💬 "纽约办公室的地址是什么？"

### 找讨论

> 💬 "关于 API 重构的决定是什么？搜一下 Slack 和 Notion"

### 做调研

> 💬 "帮我调研一下竞品 X 最近的产品更新"

### 搜索后操作

搜索往往不是最终目的——你可以在搜索基础上继续操作：

> 💬 **第一步：**
> "搜一下我们的品牌色值"
>
> 💬 **第二步：**
> "把搜到的品牌色值整理成一个表格，写到 @设计规范 页面里"

这就是 Agent 的强大之处——搜索、理解、操作，一气呵成。

## 本章小结

- Agent 的搜索覆盖 **Notion 工作区 + 连接的外部工具 + 互联网**
- 使用**自然语言**描述需求，不需要堆砌关键词
- 可以**指定时间范围**和**来源**提高精度
- 搜索默认包含互联网结果，说"只搜工作区"可以排除
- Agent 会**总结**搜索结果并**标注来源**
- 外部工具需要先在 Notion 设置中连接
- 可以直接让 Agent **阅读网页链接**的内容
- 搜索和操作可以无缝衔接——找到信息后直接让 Agent 帮你处理

下一章，我们来了解如何创建和配置自定义 Agent——让 AI 按照你的规则工作。

---

> 📌 **本章盲区声明**：搜索结果的相关性取决于底层搜索引擎的算法，可能随版本更新而变化。外部工具的搜索深度和同步频率取决于各服务的 API 限制和 Notion 的集成程度。互联网搜索结果的准确性取决于网页内容本身，Agent 不对其真实性负责。
