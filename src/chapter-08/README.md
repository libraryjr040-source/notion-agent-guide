# 高级技巧与最佳实践

前面七章覆盖了 Notion Agent 的所有核心能力。本章汇总一些实用的高级技巧和最佳实践，帮你更高效地使用 Agent。

## 提示词工程

Agent 的表现很大程度上取决于你怎么跟它沟通。以下是经过验证的提示词技巧：

### 明确 > 模糊

给出具体的名称和细节，而不是模糊的描述：

> ❌ "帮我整理一下数据库"
> ✅ "帮我在'任务跟踪'数据库里把所有状态为'未开始'且创建时间超过30天的任务归档"

### 分步 > 一口气

复杂任务拆成清晰的步骤：

> ❌ "帮我做一个完整的项目管理系统"
> ✅ "帮我：
> 1. 创建一个'项目'数据库，包含名称、状态、负责人、截止日期
> 2. 创建一个'任务'数据库，通过关联属性链接到项目
> 3. 在任务数据库里加一个看板视图，按状态分组"

### 提供示例和参考

当你想要特定的格式或风格时，给一个示例：

> 💬 "帮我写一份会议纪要，格式参考这个页面：[xxx]，包含参会人、讨论要点、行动项"

### 说明输出偏好

告诉 Agent 你想要什么样的结果：

> 💬 "用表格形式总结比较"
> 💬 "用简洁的要点形式，不要写成文章"
> 💬 "创建一个页面而不是在聊天里回复"

## 页面编辑的进阶技巧

### 精确替换 vs 全量替换

当你要求 Agent 修改页面时，它会智能地只修改需要变化的部分，而不是重写整个页面。这意味着：

- 你的页面不会因为一次小修改而被全部覆盖
- 其他人同时编辑的内容不会被意外删除

> 💡 如果你想在页面的特定位置插入内容，可以说："在 'xxx' 段落后面加上..."

### 批量查找替换

> 💬 "把这个页面里所有的 'Q3' 替换成 'Q4'"

Agent 会一次性替换所有匹配项。

### 重新组织内容

> 💬 "把这个页面的内容按主题重新组织，加上清晰的标题"

> 💬 "把这个页面转换成幻灯片格式"

Notion 支持将页面以幻灯片模式呈现，Agent 可以帮你把内容重新组织成适合演示的格式。

## 数据库的进阶用法

### 跨数据库查询

> 💬 "把任务数据库和项目数据库关联起来，给我列出每个项目还有多少未完成任务"

Agent 可以跨多个数据库查询和汇总数据。

### Linked Database（链接视图）

> 💬 "在我的项目概览页面上加一个任务数据库的链接视图，只显示状态为'进行中'的任务"

链接视图让你可以在不同页面上以不同角度展示同一份数据。

### 双向关联

> 💬 "在任务数据库和项目数据库之间建立双向关联，任务侧叫'所属项目'，项目侧叫'任务列表'"

双向关联让两个数据库互相引用，修改一侧会自动更新另一侧。

### 模板页面

> 💬 "在任务数据库里创建一个模板，包含任务描述、验收标准、相关文档三个部分，并设为默认模板"

模板就是数据库中的预设页面结构，新建记录时自动套用。

## 搜索的进阶技巧

### 缩小范围

搜索默认会跨所有源。你可以缩小范围：

- "只在 Notion 工作区搜索 xxx"（不搜网页）
- "在 Slack 里搜索 xxx"（指定来源）
- "搜索最近一周的 xxx"（限制时间）

### 多轮搜索

如果第一次搜索结果不理想，换个角度再搜：

> 💬 "搜不到，换个关键词试试，用 'xxx' 搜"

### 搜索 + 动作组合

> 💬 "搜索所有关于'Q3发布'的内容，汇总到一个新页面"

## 自定义 Agent 的进阶技巧

### 渐进式配置

不要试图一步到位，跟创建数据库一样，分步构建：

1. 先创建 Agent，写好指令
2. 测试基本功能
3. 然后逐步添加集成和触发器
4. 每次添加后都测试

### 指令的迭代优化

指令很少一次写对。观察 Agent 的行为，然后调整：

> 💬 "周报助手生成的周报太长了，在指令里加一条：每个部分最多3个要点"

### 多 Agent 协作

不同的任务用不同的 Agent：

- "周报助手" 负责生成周报
- "反馈分析员" 负责分析客户反馈
- 个人助手作为“调度中心”协调它们

## 工作流自动化模式

以下是几种常见的自动化模式：

### 模式 1：新记录自动处理

数据库新增记录时自动触发 Agent：
- 自动填充缺失属性
- 自动分类/标签
- 自动发送通知

### 模式 2：定时报告

按时间表自动生成报告：
- 每周周报
- 每日站会摘要
- 每月数据汇总

### 模式 3：跨平台同步

将外部信息同步到 Notion：
- Slack 重要消息 → Notion 页面
- GitHub Issue 变更 → 更新 Notion 数据库

### 模式 4：智能分诊

Agent 根据内容自动判断并路由：
- 客户反馈 → 分析情感 → 派发给对应团队

## 安全与权限最佳实践

### 页面验证

Notion 支持页面验证功能，确保重要文档的准确性：

> 💬 "把这个页面标记为已验证，90天后过期"

验证过期后会提醒责任人重新审核。

### 分享控制

精确控制谁能看到和编辑你的内容：

> 💬 "把这个页面分享给 Alice，只读权限"

> 💬 "把这个页面公开分享，让所有人都能看到"

### 自定义 Agent 的最小权限

反复强调：只给 Agent 它需要的权限。不要图方便给全部权限。

## 效率技巧

### 善用 @ 提及

在对话中直接 @ 页面或数据库，Agent 就能立即访问它，无需搜索：

> 💬 "查看 @任务跟踪 数据库里本周到期的任务"

### 一次对话多个任务

同一个对话中可以连续做多件事，Agent 会记住上下文：

> 💬 "查看任务数据库里本周完成的任务"
> 💬 "把结果汇总到一个新页面"
> 💬 "再发到 Slack #team 频道"

### 用选择上下文

在页面中选中一段内容再唤起 Agent，它会知道你在说哪部分：

> 💬 "帮我改写这段，语气更正式一些"

## 本章小结

- **提示词质量决定输出质量**：明确、分步、给示例
- **精确编辑** > 全量重写：保护已有内容
- **数据库的高级功能**：跨库查询、链接视图、双向关联、模板
- **搜索可以精确控制**：指定源、限制时间、组合动作
- **自动化模式**有四种常见类型：新记录处理、定时报告、跨平台同步、智能分诊
- **安全第一**：最小权限、页面验证、精确分享

下一章是常见问题与排障指南，帮你解决使用中可能遇到的问题。
