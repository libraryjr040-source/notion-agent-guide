# 前言

## 这本书是什么

这是一本关于 **Notion Agent** 的使用指南——帮助你理解和高效使用 Notion 内置的 AI 助手。

无论你是刚接触 Notion Agent 的新手，还是想深入挖掘其潜力的老用户，这本书都能帮到你。

## 谁适合读这本书

- **Notion 用户**：已经在使用 Notion，想了解 AI 助手能做什么
- **效率爱好者**：想用 AI 自动化日常工作流
- **团队管理者**：想为团队搭建智能化的工作系统
- **好奇的探索者**：想了解 AI Agent 在实际工具中的应用

你不需要任何编程或技术背景。

## 如何阅读

本书分为四个部分：

1. **基础篇**（第1-2章）：了解 Agent 是什么，学会基本对话
2. **核心能力篇**（第3-5章）：掌握页面、数据库、搜索三大核心能力
3. **进阶篇**（第6-8章）：创建自定义 Agent、连接外部工具、高级技巧
4. **参考篇**（第9章+附录）：常见问题解答和速查表

建议新手从第一章开始顺序阅读。有经验的用户可以直接跳到感兴趣的章节。

## 关于本书的特别说明

本书有一个独特之处：**它本身就是由 Notion Agent 撰写的**。

在整个创作过程中，Notion Agent 完成了从大纲设计、素材研究、内容撰写到代码仓库管理的全部工作。人类作者（我们称之为"皇上"）负责方向确认和最终验收。

这本身就是 Notion Agent 能力的最好证明。

## 盲区声明

每章末尾都有一个「盲区声明」，标注该章内容的局限性。这些声明是诚实的——Agent 知道自己不知道什么，也会告诉你。

本书的主要盲区包括：
- Notion 产品功能可能随版本更新而变化
- 某些高级功能可能需要特定的 Notion 计划等级
- Agent 的具体行为可能因上下文和模型版本而有细微差异
- 外部集成（MCP 服务器等）的具体能力取决于服务提供方

现在，让我们开始吧。
