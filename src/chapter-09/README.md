# 常见问题与排障

在使用 Notion Agent 的过程中，你可能会遇到一些困惑或意外情况。本章收集了最常见的问题和解决方案。

## 基础问题

### Agent 没有回应我想要的结果

**可能原因**：指令太模糊。

**解决方案**：
- 提供更具体的上下文（页面名称、数据库名称）
- 分步骤描述你想要的操作
- 如果结果不对，告诉 Agent 哪里不对，让它修正

> 💬 "不对，我说的不是这个数据库，是叫'任务跟踪'的那个"

### Agent 说找不到某个页面或数据库

**可能原因**：
1. 名称拼写不准确
2. 页面在你没有权限的区域
3. 页面已被删除或归档

**解决方案**：
- 用 @ 提及直接引用页面/数据库
- 检查页面是否在回收站中
- 尝试用不同的关键词搜索

### Agent 创建的页面不在我期望的位置

**可能原因**：没有指定父级位置。

**解决方案**：明确告诉 Agent 把页面放在哪里：

> 💬 "在'项目文档'页面下面创建一个新页面"
> 💬 "在任务数据库里新建一条记录"

如果页面已经创建在了错误的位置，可以让 Agent 移动它：

> 💬 "把这个页面移到'项目文档'下面"

## 数据库相关问题

### 属性值没有正确设置

**可能原因**：属性名大小写不匹配。

属性名是**大小写敏感**的。"Status" 和 "status" 是两个不同的属性。

**解决方案**：让 Agent 先查看数据库结构：

> 💬 "先看看这个数据库有哪些属性，然后再更新"

### 日期属性设置不生效

**可能原因**：日期属性有特殊的格式要求。

日期属性实际上由三个部分组成：
- 开始日期（`date:属性名:start`）
- 结束日期（`date:属性名:end`）
- 是否包含时间（`date:属性名:is_datetime`）

**解决方案**：让 Agent 处理就好——当你说"把截止日期设为1月15日"时，Agent 知道如何正确设置这三个部分。如果不生效，检查属性名是否完全匹配。

### 查询数据库没有结果

**可能原因**：
1. 筛选条件太严格
2. 属性名不匹配
3. 多选/关联属性的值格式特殊

**解决方案**：
- 先不加筛选条件查看所有数据
- 确认属性名和选项名的准确拼写
- 对于多选属性，值是以数组形式存储的

### 想批量更新数据库但 Agent 说不行

**原因**：超过 20 行的批量更新需要使用 Autofill Agent。

**解决方案**：

> 💬 "帮我创建一个自动填充 Agent，批量给所有任务生成摘要"

或者缩小范围到 20 行以内：

> 💬 "先给最近的 10 条记录生成摘要"

## 页面编辑问题

### 编辑后内容被意外覆盖

这种情况很少见——Agent 默认使用精确替换而非全量覆盖。但如果你要求"重写整个页面"，旧内容会被替换。

**解决方案**：如果只想修改部分内容，明确指出位置：

> 💬 "只修改第二段，其他不要动"

### 页面里的数据库块消失了

Agent 不能通过页面编辑创建或修改数据库块。如果你在编辑过程中意外提到了数据库块区域，可能会导致问题。

**解决方案**：
- 数据库相关操作走数据库功能，不要通过页面编辑
- 如果数据库块消失了，检查页面编辑历史

### 无法编辑某个页面

**可能原因**：
1. 页面已被锁定
2. 页面已被删除
3. 你没有编辑权限

**解决方案**：检查页面状态：

> 💬 "这个页面的状态是什么？是不是被锁定了？"

## 搜索相关问题

### 搜索结果不相关

**解决方案**：
- 使用更具体的关键词
- 指定搜索范围（"只在 Notion 里搜索" / "在 Slack 里搜索"）
- 限制时间范围（"搜索最近一周的"）
- 换个角度搜索，用不同的关键词

> 💬 "搜索结果不太对，换个关键词，用'产品发布计划'搜"

### 搜索连接源没有结果

**可能原因**：
1. 对应的连接未建立或已过期
2. 搜索范围不对

**解决方案**：

> 💬 "检查一下我的连接状态"

如果连接需要重新授权，Agent 会引导你完成。

## 自定义 Agent 问题

### Agent 创建后什么都做不了

**原因**：自定义 Agent 默认没有任何权限。

**解决方案**：给它添加需要的集成和权限：

> 💬 "给这个 Agent 添加 Notion 权限，让它能访问任务数据库"

### 触发器没有生效

**可能原因**：
1. 触发器未启用
2. 触发条件未满足
3. 配置后没有测试

**解决方案**：

> 💬 "检查一下周报助手的触发器配置，看看是否启用了"
> 💬 "帮我测试一下这个 Agent"

### Agent 的行为不符合预期

**解决方案**：检查并优化指令页面：

> 💬 "看看周报助手的指令页面，把'每个部分最多3个要点'加进去"

指令优化是一个迭代过程——观察行为，调整指令，再测试。

## 连接相关问题

### 连接显示需要重新授权

外部服务的授权可能会过期。

**解决方案**：

> 💬 "帮我重新连接 Slack"

Agent 会发起新的授权流程。

### MCP 服务器连接失败

**可能原因**：
1. 服务器地址不正确
2. 服务器未运行
3. 网络问题

**解决方案**：确认服务器地址和运行状态，然后重试连接。

## 通用排障步骤

当遇到问题时，可以按这个顺序排查：

1. **确认权限**：你（或 Agent）是否有权限访问目标资源？
2. **确认名称**：页面/数据库/属性的名称是否准确？
3. **确认状态**：目标是否被删除、归档或锁定？
4. **确认连接**：需要的外部连接是否已建立且状态正常？
5. **简化问题**：把复杂请求拆成简单步骤，逐个测试
6. **换个方式**：如果一种方法不行，换个角度描述你的需求

## 获取帮助

如果你遇到了本章没有涵盖的问题：

- **Notion 帮助中心**：让 Agent 搜索 Notion 帮助文档
  > 💬 "在 Notion 帮助文档里搜索如何设置页面权限"

- **描述问题**：尽可能详细地向 Agent 描述你遇到的情况，它通常能帮你诊断问题

## 本章小结

- 大多数问题来自**权限不足**、**名称不匹配**或**格式不正确**
- Agent 处理大多数格式问题（如日期、多选），你只需要用自然语言描述
- 搜索不到结果时，换关键词、指定范围、限制时间
- 自定义 Agent 问题通常是权限或指令配置不当
- **分步排查**是最有效的方法：权限 → 名称 → 状态 → 连接 → 简化
- 遇到不确定的问题，直接问 Agent，它可以帮你诊断
