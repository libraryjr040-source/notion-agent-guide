## 核心论点

> Notion Personal Agent 能够依据 write-book skill + 5-Phase Workflow，在皇上提供方向确认和最终验收的条件下，全权执行写出一本尽可能全面（附显式盲区声明）、通俗易懂、具备可操作性的《Notion Agent 使用指南》。

## 设计原则

1. **通俗易懂**：用自然语言和对话示例，不暴露技术实现
2. **可操作性**：每章都有具体的对话示例（💬 格式）
3. **显式盲区**：每章末尾有盲区声明
4. **渐进式**：从基础到进阶，概念依赖清晰
5. **实用参考**：附录提供速查表
