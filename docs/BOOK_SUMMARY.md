## Chapter 1: Notion Agent 是什么
- **Status**: ✅ Done
- **Word count**: ~3500
- **Key points**:
  1. Agent 不只是聊天——能直接操作 Workspace（创建/编辑/删除页面和数据库）
  2. Agent 有明确边界：不能做管理操作、不能访问未授权内容、不能联系外部人员
  3. Personal Agent（每人一个，继承用户权限）vs Custom Agent（可创建多个，默认无权限）
  4. 全书三阶段认知递进：使用者→创造者→架构师
- **Key analogies**:
  - Workspace = 共享办公室
  - Page = 乐高底板（可独立存在，也可嵌入结构）
  - Database = 智能文件柜
  - Teamspace = 办公室里的会议室
  - Agent = 私人助理
  - Custom Agent = 雇佣的专职员工（默认无权限）
- **Cross-references**: Ch2（第一次对话预告）, Ch3/Ch4（Page/Database 详细讲解预告）, Ch6（Custom Agent 详细讲解预告）
- **New terms**: Workspace, Page, Database, Teamspace, Agent, Personal Agent, Custom Agent, Instructions, Skills, Trigger, MCP
- **Review notes**: Ch1 类比需在后续章节保持一致。"乐高底板"在 Ch3 扩展为"底板上可以放各种积木"，Ch4 扩展为"底板也可以放进柜子里变成一行数据"。"智能文件柜"在 Ch4 扩展为"文件柜里有分区 = Data Source"。
